# Changelog

## 1.2.0

### Added

- The page now shows your reading progress under the title, like "2 of 4 read".

### Changed

- The server's startup message now reads "Readlist is running at ...".

### Fixed

- The server no longer crashes when it receives a malformed request URL; it replies with a 400 error.
- The Add button now stays on the same row as the Title and Author fields.

## 1.1.0

### Added

- New `GET /api/stats` endpoint that returns how many books you have and how many you've read.

### Changed

- Nothing.

### Fixed

- Nothing.
